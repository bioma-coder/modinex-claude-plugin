# Draft questions for MoGenix

Examples illustrate private draft creation and status lookup, not live publishing. Replace placeholders with user-confirmed values. Confirm unresolved item identity or proposed content before saving. Each scenario has equivalent English, German and Arabic wording.

1. Agreed description
   - EN: Prepare a private draft replacing the English description of [item] with [agreed text]. Keep the live menu unchanged.
   - DE: Erstelle einen privaten Entwurf, der die englische Beschreibung von [Gericht] durch [vereinbarten Text] ersetzt. Die aktive Speisekarte bleibt unverändert.
   - AR: جهّز مسودة خاصة لاستبدال الوصف الإنجليزي لـ[الصنف] بـ[النص المتفق عليه] مع بقاء المنيو الحالي دون تغيير.
2. German name correction
   - EN: Prepare a draft correcting the German name of [item] to [correct name], without changing the other languages.
   - DE: Erstelle einen Entwurf zur Korrektur des deutschen Namens von [Gericht] auf [richtiger Name], ohne andere Sprachen zu ändern.
   - AR: جهّز مسودة لتصحيح الاسم الألماني لـ[الصنف] إلى [الاسم الصحيح] بدون تعديل اللغات الأخرى.
3. Agreed Arabic wording
   - EN: Save our agreed Arabic description for [item] as a draft for review.
   - DE: Speichere unsere vereinbarte arabische Beschreibung für [Gericht] als Entwurf zur Prüfung.
   - AR: احفظ الوصف العربي المتفق عليه لـ[الصنف] كمسودة للمراجعة.
4. Explicit EUR price proposal
   - EN: Prepare a draft changing [item] to EUR [amount], after showing me the current and proposed prices.
   - DE: Bereite eine Preisänderung für [Gericht] auf [Betrag] EUR als Entwurf vor und zeige mir zuerst den bisherigen und den vorgeschlagenen Preis.
   - AR: جهّز مسودة لتغيير سعر [الصنف] إلى [المبلغ] يورو بعد عرض السعر الحالي والمقترح عليّ.
5. Draft follow-up
   - EN: Check the status of draft [plan ID] and show the recorded changes without approving or executing them.
   - DE: Prüfe den Status von Entwurf [Plan-ID] und zeige die gespeicherten Änderungen, ohne sie zu genehmigen oder auszuführen.
   - AR: راجع حالة المسودة [رقم المسودة] واعرض التعديلات المسجلة بدون الموافقة عليها أو تنفيذها.

For EUR price drafts apply the parent skill's currency verification and exact minor-unit conversion. For other currencies explain the current limitation. Never reinterpret a status request as permission to create a replacement draft.
